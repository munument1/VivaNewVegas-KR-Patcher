# Viva New Vegas 한국어 패쳐 v1.0.7.7 — 한글 인코딩 안전성 개선

이번 버전은 **v1.0.7.6의 번역·Pretendard 글꼴·터미널 고정폭·키 안내 UI 플러그인**을 그대로 유지하면서, 한국어 tNVSE DLL의 인코딩 경계를 개선합니다.

- 잘못된 UTF-8과 불완전한 바이트 시퀀스의 자동 변환을 차단합니다.
- CP949에 표현할 수 없는 문자를 물음표로 손실시키지 않고 원래 입력 바이트를 보존합니다.
- 기존 UI GMST·키 안내·rich-text·아이콘 치환 기능을 유지합니다.
- 새로운 DLL을 고정된 upstream 소스에서 Win32로 빌드하고 대응 소스 ZIP을 함께 제공합니다.
- 자동 검증에서 v1.0.7.6 대비 번역·폰트·UI·작업자 파일의 불필요한 변경이 있으면 배포를 중단합니다.

**업데이트:** 새 실행파일에서 Output을 새로 생성하세요. MO2와 게임을 종료하고 기존 번역 파일을 백업한 뒤 안내에 따라 병합합니다. 기존 Output을 재사용하거나 DLL만 바꿔서는 안 됩니다. 기존 세이브와 게임 원본은 삭제하지 마세요.

**검증 범위:** Windows DLL 및 C++ 회귀 검사, 패쳐 단위 테스트, 패키지 검사, 리소스 해시 검증. 실제 VNV Extended 환경의 모든 대화 선택지·효과 종료 알림·문 안내·HUD는 전수 게임 검증이 완료되지 않았습니다. Nuclear Sunset 전용 TTW 스크립트는 이 버전에 포함되지 않습니다.
